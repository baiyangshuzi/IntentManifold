# IntentDynamics（机器意图动力学）

> **初具"机器意图动力学"雏形的多层级语义指纹系统**——首次将"根意图"从抽象认知概念转化为**可计算的几何引力场**，揭示人类思维流动区别于 AI 概率滑行的动力学特征（波浪、转折、耦合），并给出突破自回归范式的实证路径与三层引擎架构构想。

## 一、核心命题

传统自回归模型只有一个驱动力：**局部概率最大化**——没有"为什么写这句话"的持续状态。本系统提出：

> **智能的本质特征之一是文本生成中存在可测量、可干预、可训练的"意图状态"——它不直接决定每一个词，但为所有词的选择提供引力场。**

## 二、核心发现（全部基于实测数据——可复现）

### 1. 意图流转捕捉（人类 vs AI 思想动力学画像）

| 指标（句元级） | 人类 | AI | d / p |
|---|---|---|---|
| 维度跳跃度（波浪 vs 平坦） | 0.310 | 0.257 | **+2.16 / <0.001** |
| 转折峰谷陡度（话题开合） | 0.468 | 0.381 | **+2.09 / <0.001** |
| 长程记忆 Hurst（回环能力） | 0.621 | 0.457 | 天行健 vs archives |
| 转移熵（信息流自由度） | 0.0124 | 0.0194 | -0.79（AI 机械） |
| 主题×指代耦合 | +0.517 | +0.432 | 方向支持 |

**一句话**：人类=根意图引力场中的**自由波动**（有记忆的回环、有深度的转折、自由的流动）——AI=**无场平坦滑行**（无起伏、金鱼记忆、机械流动）。

### 2. 意图状态解剖（64 维维度图谱）

- **解释性×判别力反比**：未解释 11 维人机差异中位 d=0.53（已解释 42 维 0.32）——深层信号=判别信号本体
- **dim48=指代链/衔接维度**（三证合一：复合追溯+双模型一致+因果控制指代密度 -0.42）
- **dim10=主题组织维度**（扰动↑主题词密度 +0.12~+0.23）
- **极性分组**：人类组织组（dim10/11/34/46/48/59）vs AI 特征组（dim22/26/43/52/5）

### 3. 结构/表达层干预（推理期谱系——201 runs/22 条件——非意图流转层）

**定位（与论文 §5.0 一致）**：本谱系**基于结构/表达层指标**（判别器静态投影 sent_proj——"贴核心"、主题词保持、logits 偏置、beam 选优、虚拟 token 注入）——干预目标是**静态组织一致性**（贴核心）——**早于意图流转测量（v0.74）——完全没有使用流转指标**（跳跃/转折/Hurst/TE/耦合——那些是 §2 的测量/监测层观测证据，不是现有干预的目标函数）。**把流动指标用作干预目标（如"生成轨迹转折陡度接近人类"）是意图动力学引擎的构想（§4——未实现）**。

谱系：概率层 17-25% → logits 40% → beam 51% → 种子+beam **82%** → 虚拟 token 通道 → **vt_seed_beam 117%** → **vt_gate_beam 103%（成本降 67%——推荐）**——最小干预原则（种子+beam 是最小有效组合）——"何时注入"比"注入什么"重要。

### 4. 意图动力学引擎（三层架构构想）

**根意图势场**（锚——引力场最低点——仅偏离时回拉）→ **意图轨迹规划器**（学习人类波动模式——目标状态分布）→ **意图引导执行层**（虚拟 token 注入+门控）——从"词语接龙"到"围绕根意图的目标驱动型推演"。

## 四、环境与依赖

- **Python 3.13**（Windows 实测——Linux/macOS 亦兼容）
- torch / transformers（≥4.40——Qwen2.5-0.5B 生成）
- sentence-transformers（bge-small-zh-v1.5——判别器编码器）
- scipy / numpy / matplotlib / jieba / sklearn
- **本地模型**（HF_HUB_OFFLINE=1 使用缓存）：`Qwen/Qwen2.5-0.5B`（生成——0.5B base）——`BAAI/bge-small-zh-v1.5`（编码）
- 生成实验需 NVIDIA GPU（MX570 2GB 实测可跑——fp16）——分析实验纯 CPU 可跑
