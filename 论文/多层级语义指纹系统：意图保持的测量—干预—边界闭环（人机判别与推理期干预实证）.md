## 摘要

本文提出多层级语义指纹系统：以判别器中间层 64 维激活为风格指纹，将长程意图保持能力定义为可计算、可定位、可与人类基线对照的几何量（句元投影一致性 sent_proj、轨迹粘合 traj、篇核心投影等）。实测证据链：严格配对 60 对 + 多段连续 35 组 + 完全未入训独立测试集 32 对（DS/Qwen 双模型）+ 双语 2×2×3（60 篇长文档）+ 4956 段滑窗 + 长文档章节对照——判别力三重验证（白话域 d 1.0-5.5——独立集+双模型方向一致——段内均值核心跨语言一致 zh/en d≈2.1）；边界诚实测定（官方评价体/改写/文言——独立集三层级双模型归零——边界模型无关）；机制可解释（主题词密度人类 8 倍 d 1.67——指纹 53/64 可解释）。在此基础上完成**推理期干预实证（201 runs 22 条件）**：判别器推理期价值=监测（触发精准）+评估（beam 选优）——谱系从概率层 17-25% 逐级升级——**句级种子+beam5=82% oracle（最小干预原则）**→ 虚拟 token 注入通道（MLP 64 维指纹→嵌入空间——通道优于 logits 载体 +16 点）→ 三层叠加 vt_seed_beam=**117% oracle（新最高点）**→ Kalman 预测门控（实现问题修复后 r 0.147→0.389）驱动资源分配——**vt_gate_beam=103% oracle 但成本降 67%（0.37 秒/oracle 点——质量-成本最优形态）**；无 beam 测试定论：种子效应依赖 beam（纯种子 -1%）——beam 净贡献 36 点不可替代——门控 46% 为无 beam 最优。频域/意图先验数据前提验证：段级意图轨迹≈白噪声（F1 FAIL——傅里叶前提不成立）——Kalman 观测模型失配实锤（innovation 自相关 -0.85）。能力解耦实证：意图锚定对推理准确率零迁移（常规 53%→50%/抗污染 25%→22%）——长文语义保持零差异（0.94+）——框架能力边界=组织层（聚焦/长度）——语义层需训练期干预（判别器指纹经映射层 φ 作可微分损失通道——接口已声明）。全部数据可复现（固定 seed 确定性采样——数据资产完整归档）。
## 0. 术语表（本系统独有名词附注——便于读者理解）

> 术语分层（简化——审稿⑥）：**核心术语 6 项**（句元/风格指纹/意图核心/投影/轨迹粘合/方向一致性）——其余为**指标名**（对应具体测量公式——不视为独立术语）。通用统计术语（Cohen's d/AUC/t 检验）不在此列。

**核心术语（6 项）**：
| 术语 | 定义 | 对应的测量指标 |
|---|---|---|
| **「句元」** | 句子的子结构——最小语义单元 | 所有句级测量的单位 |
| **「风格指纹」（指纹）** | 判别器中间层 64 维激活——人机风格差异维度的压缩表示 | 所有投影/余弦计算的特征向量 |
| **「意图核心」** | 局部单元指向的中心点——分两种锚：「段内均值核心」（句元均值——主口径）与「外部锚核心」（prompt/首段——次口径——对称性已检验）；**全局版=「篇核心」**（全篇句元指向中心——被指向的核心思想） | 投影的锚对象（一对一） |
| **「投影」** | 归一化指纹与核心的余弦——贴核心程度 | sent_proj/word_proj/篇核心投影（一对一） |
| **「轨迹粘合」** | 相邻句元投影差的绝对值均值——核心漂移 | traj（一对一） |
| **「方向一致性」** | 逐对差值符号统计——判别可用性判据 | 逐对比较（一对一） |
| **「段」** | 文档按非空行切分的自然段（≥30 字且非章节标题行）——「段序列」=全文按顺序的段列表 | 段落级测量的单位（n_para） |
| **「句元」** | 句子的子结构——最小语义单元（split_subclauses 切分——len≥3 过滤） | 句级测量的单位（n_sent） |
| **「首 3 段」（first3）/「末 3 段」（last3）** | **段序列的前 3 段/后 3 段的投影均值**（不是"开头第一句"也不是"第一章"——是全文按顺序的前 3 个自然段 vs 最后 3 个自然段） | 首末段差 drop = first3 − last3——**"段首/段末"=前 3 段/后 3 段（每段一值——3 段平均降噪）** |
| **「首末段差」（drop）** | 首 3 段投影均值 − 末 3 段投影均值——正=开头贴核心而末尾漂移（首锚口径的"长程衰减"度量） | first3/last3（一对一） |
> （其余原术语已按分层归入指标名/现象名词——详见各章节定义——「外部锚核心」「篇核心」为锚的两种实例）


## 1. 引言

### 1.1 问题起源（工程动机——本研究的出发点）

本研究最初源于一个**叙事辅助写作系统**的工程实践：该系统以"最大化放大 AI 写作能力"为目标，使用大模型生成中文长篇叙事文本。工程中遇到一个持续无法解决的问题——**生成的文本即使经过提示词工程与局部词汇替换等多轮迭代，仍可被稳定识别为机器生成**。实测数据（v0.64）：对 AI 初稿做反 AI 处理（局部改词）后，其指纹特征与 AI 基线完全一致——句元投影 0.846（=AI 水平，人类 0.977）、相邻句元一致性 0.627（=AI，人类 0.938）、词相邻 0.622（=AI，人类 0.824）——**换词不可能人类化**。这一现象促使我们提出核心猜想：

> **AI 与人类写作的差异可能不在表面词汇，而在局部句元的组织方式本身。**

为验证这一猜想，我们训练了判别器并分析其内部表征——由此发展出本文的"风格指纹"框架。这一动机解释了本研究与通用 AI 检测工作的根本差异：我们关心的不是"如何判 AI"，而是"AI 的组织方式与人类差在哪、能否量化、能否据此改进生成"——判别是这一目标的衍生工具。

### 1.2 背景

大模型生成的文本在句法与词汇层面已接近人类水平，但组织方式存在系统性差异。现有 AI 检测技术四类：数字水印（需模型方配合——开放域不可用）、统计/风格特征（易被改写绕过）、神经网络分类器（黑盒——跨域泛化差）、混合方法。共同局限：①不可解释（只给结论——不定位"哪里像 AI"）；②跨域泛化未经验证（大多单一文体测试）。

**本文定位（差异化——精准表述）**：现有研究多聚焦于**单一时刻的质量评估**（连贯性打分、指令对齐度）或**特定类型的漂移**（主题转移、事实一致性衰减）——但尚未有工作将**生成过程中的意图漂移**作为一个**可计算、可层级定位、可与人类基线对照**的能力子域来系统研究。本文的独特贡献：①**统一测量框架**——词/句元/段/篇的意图保持统一到同一几何量（投影一致性——非零散指标）；②**人机对照效应量**——不只测 AI 自身漂移，而是与人类写作统计对比（"差异有多大"而非"是否存在"）；③**边界条件系统测定**——何时可判/不可判及失效机理（模板型/锚定型/饱和型）；④**锚口径与循环性实证**——主动检验测量工具本身的有效性（方法学贡献）；⑤**意图漂移作为能力子域**——为训练干预与 AGI 评测提供接口。

### 1.3 意图锚点假说（本系统的理论基础——部分验证）

> **人类写作围绕稳定的「意图核心」组织语言——段内句/词向核心收敛；大模型自回归生成是局部最优拼接——缺乏全局意图锚点——生成过程发生可测的「风格指纹」漂移。**

## 2. 方法（模型数学建模与分析）

### 2.1 判别器模型（ParaDiscNN——数学建模）

**结构**（bge 编码器 + 三层 MLP）：

```
输入:  x ∈ R^512          （bge-small-zh-v1.5 句元向量——L2 归一化）
h₁ = ReLU(LN(W₁x + b₁))    W₁ ∈ R^{256×512}, b₁ ∈ R^256
h₂ = ReLU(LN(W₂h₁ + b₂))   W₂ ∈ R^{64×256},  b₂ ∈ R^64
ŷ = σ(W₃h₂ + b₃)           W₃ ∈ R^{1×64},   b₃ ∈ R —— σ=sigmoid
```

**训练目标**（二分类交叉熵）：

```
L = -[y·log ŷ + (1-y)·log(1-ŷ)]      y=1 为 AI 段落
优化: AdamW——学习率 1e-3——批 256——早停（验证集 BCE）
评估: 5 折 StratifiedKFold（按段落切分——防文档级泄漏）——折内阈值按验证集权衡（检出率 vs 误抓率）——5 折后全量重训落盘
```

**两代训练**：
- **v1（文学域）**：人类=龙族 70%+诛仙 30%；AI=696 篇现代 AI 语料（6000/6000 段）——验收：AI 检出 100%/龙族误抓 1%/诛仙 2%——AUROC 0.95+。
- **v2（泛用性——当前默认）**：v1 数据 + 687 段跨域 AI 样本（DS 生成 5 域：学术 148/口语 150/短文本 150/仿写龙族 121/仿朱自清 119）+ 对应人类样本（评论 87/论坛 353/标题 223）混入——AI 7252 vs 人类 8000——5 折 97.0%/AUROC 0.996——未见样本（新 Prompt 生成）跨域 0.918-1.000——原域保持（AI 100%/误抓 1-4%）。

**为何中间层可作为指纹**：判别器训练被迫学习"人机风格差异的本质维度"——h₂（64 维瓶颈）即其压缩表示——直接读取已学特征（冻结——无梯度）——无需新训练。

### 2.2 指纹空间（提取数学形式与几何性质分析）

**指纹提取**（h₂ 补最后 ReLU——完整 64 维）：

```
f(x) = ReLU(LN(W₂·ReLU(LN(W₁x + b₁)) + b₂))   # f ∈ R^64
```

**段核心（mean 核心）**——段内句元指纹均值：

```
c = normalize( (1/n)·Σᵢ f(xᵢ) )     # xᵢ = 段内第 i 个句元——n = 句元数
```

**几何性质（为什么"投影"有效而"两两余弦"无效——实测+数学解释）**：
1. 两两余弦（句元对指纹点积）实测 AUC 0.55——无判别力——**数学原因**：成对余弦只度量"局部相对方向"，不包含"相对核心的方向信息"——人类与 AI 的句元内部两两相似度相近（都高），差异在"整体指向"。
2. 投影 = 每句元指纹与核心的余弦——度量"该句元在多大程度上朝核心方向对齐"——核心 c 是判别器学到的"人类风格方向"的鲁棒估计（均值操作降噪）——投影把"整体指向"压缩成标量——判别力 90.4%（人类投影 0.972 vs AI 0.807）。
3. PCA 主导方向版核心（段内指纹主成分——更鲁棒的"主导塑造方向"估计）：判别力 94.0%——方向估计的稳健性影响判别上限。
4. 指纹空间随重训偏移（v1→v2 绝对值略降——人类投影 0.972→0.941 级）——判别力保持——阈值需按代际重定标。

### 2.3 七维指标（数学定义）

设句元指纹归一化 f̂ᵢ = f(xᵢ)/‖f(xᵢ)‖，段核心 ĉ = c/‖c‖：

| 维度 | 数学定义 | 计算类型 |
|---|---|---|
| disc「判别分」 | (1/n)·Σᵢ σ(W₃f(xᵢ)+b₃) | 模型计算 |
| sent_proj「句元投影」 | (1/n)·Σᵢ f̂ᵢ·ĉ | 规则统计 |
| traj「轨迹粘合」 | (1/(n-1))·Σᵢ‖(f̂ᵢ₊₁·ĉ) − (f̂ᵢ·ĉ)‖ | 规则统计 |
| l7_adj「相邻句元」 | (1/(n-1))·Σᵢ f̂ᵢ·f̂ᵢ₊₁ | 规则统计 |
| word_proj「词投影」 | (1/n)·Σᵢ (1/mᵢ)·Σⱼ ĝⱼ·f̂ᵢ  （ĝⱼ=词指纹归一化——mᵢ=第 i 句元词数） | 规则统计 |
| word_adj「词相邻」 | (1/n)·Σᵢ (1/(mᵢ-1))·Σⱼ ĝⱼ·ĝⱼ₊₁ | 规则统计 |
| entropy「词熵」 | −Σₖ (cₖ/N)·ln(cₖ/N)  （cₖ=词频——N=总词数） | 纯规则 |

判别分=模型计算（MLP 权重可训练——v1→v2 重训改变它）；六维=规则统计（不依赖训练域——双侧差异始终明显——v1 跨域"失效"是 MLP 未做跨域分辨训练——维度差异一直在——v2 将差异喂给 MLP 后权重自适应——AUC 回升）。

### 2.4 判别与统计方法

- **效应量**：独立样本 Cohen's d = (x̄_h − x̄_a)/s_pooled——主判据（特征优先原则）。
- **配对 t 检验**：逐对差值——双侧 p 值。
- **方向一致性**：逐对差值符号统计（正/反/无差）——小样本下比 AUC 更稳健的可用性判据。
- **整合判别**：11 维特征（七维+段落级四维）→ StandardScaler + LogisticRegression → **留一法（LOO）**——每样本用其余样本训练——诚实评估小样本泛化——**AUC 仅大致可靠**（每域 5-20 对——大效应可信——中等效应可能波动）。
- **转场-漂移窗口**：「恢复比 R」= 当前段段内方差/滑动基线方差（W=5）——实测误报率 46%——仅作探索报告（4.3）。

### 2.5 四层级测量框架（含实测修正声明）

| 层级 | 指标 | 实测判别力 |
|---|---|---|
| 词级 | word_proj/word_adj | **有信号**（现代域 d 0.7-4.4） |
| 句元级 | sent_proj/traj/l7_adj | **信号最强**（现代域 d 2.7-5.5） |
| 段落级 | 段内投影 std/相邻段差 | **无独立信号**（4.3 实测——聚合视角） |
| 篇章级 | 投影衰退斜率/章级轨迹（段内均值口径）/篇核心投影（全局锚口径） | **无线性长程趋势**（章级——段内均值与篇核心口径一致）——**但篇核心投影（贴附水平）配对级判别显著**（d 2.04-2.09——§4.5.6） |

## 3. 实验设计

### 3.1 测试总原则
1. **严格配对**：每篇人类文本↔同主题/同体裁/同长度量级 AI 文本（不拿 A 类人类比 B 类 AI）。
2. **特征优先**：核心验收=维度均值差+效应量 d——MLP/AUC 仅作最后线性可分验证。
3. **长度统一**：全部 ≥100 字（古文 ≥80）。

### 3.2 四组实验
- **实验一**：严格配对单段 60 对×5 域（人类：龙族/诛仙/人民网时评/澎湃自述特稿/天行健/三国演义——AI：DS-v4-flash 严格配对生成）。
- **实验二**：段落级探索（龙族 4956 段全量滑窗 + archives 6 章真实 AI 长篇 146 段 vs 天行健连续段）。
- **实验三**：多段连续配对 35 组×4 段×6 域（人类=原文连续段——真实转场；AI=连续场景生成）——11 维整合 LOO。
- **实验四（v0.66-4——审稿回应）**：①完全未入训独立测试集 32 对（澎湃新文章 20 段白话叙事 + 新华时评 12 段官方评价体——AI 全新 prompt 生成——含双模型 DS/Qwen 对比与循环性实证）②长文档实验（3 篇 AI 长文 vs 人类对照——首锚漂移）③外部锚核心对称性检验 ④bootstrap CI + BH-FDR 校正——详见 §4.5。

## 4. 实验结果

> **AUC 可靠性声明（重要）**：本文所有 AUC 基于小样本（单段实验每域 10-20 对；多段连续每域 5 组——LOO 评估）。**AUC 数值仅大致可靠**——大效应（d>1.5）可信；中等效应（d 0.5-1.5）可能波动；LOO 在小样本上偏乐观/偏悲观均可能。**主判据为效应量 d 与方向一致性**——AUC 作参考。统计检验均附 p 值（配对 t 检验）。关于小样本结论可靠性的专门讨论见 §5.7。

### 4.3 实验二：段落级探索（4956 段滑窗 + archives）

**人类基线（龙族 4956 段）**：段内投影 std 中位 0.039（p25 0.015/p75 0.092——**30% 人类段 <0.02**）；段均值中位 0.950；转场处（全局 p90 跳变）「恢复比 R」中位 1.91——但 **46% 跳变不恢复**（R<1.5）；重置机制（句元余弦放大 2 倍）仅 3% 触发（余弦 0.889→0.786——降 12%）。

**archives 真实 AI 长篇（146 段 vs 天行健连续段）**：段均值人类 0.849 vs AI 0.793（d +1.02——p<0.001）；相邻段差人类 0.066 vs AI 0.038（人类 1.7×——AI 段落间平滑——真实连续文本成立）；AI 6 章均值轨迹 [0.784,0.775,0.793,0.793,0.792,0.815]（+0.006/章——**无长程衰退**）；人类 6 等分 [0.843,0.852,0.88,0.84,0.834,0.838]。

**结论**：段落级无独立判别信号（段内 std=句元级聚合）；「转场-漂移」滑窗误报率 46%——不可产品化；**篇章级在段内均值核心口径下无线性长程趋势**——但注意：**该口径测的是段与段之间的延续——不否定全局贴附（篇核心口径——全篇句元指向中心——配对级判别显著 d 2.04-2.09——§4.5.6）**——两种口径回答不同问题（段间延续 vs 整体贴附）。

### 4.4 词熵长度混杂（方法学）

文言输入原文域 entropy d+2.44（人类 5.21-5.62 vs AI 4.83-4.99）——人类段长 900-1250 字为 AI 537-620 字的 2 倍——**截断到 AI 长度后 4.78-4.90 vs 4.83-4.99——差异消失**。跨组熵对比必须长度对齐。

### 4.5 审稿回应实验（v0.66-4——独立测试集/循环性/双模型/外部锚/长文档/CI-FDR）

#### 4.5.1 完全未入训独立测试集（①——32 对）
- **构建**：人类侧=澎湃 10 篇新文章（裸辞/摆摊/工厂自述——白话叙事 20 段——从未入训）+ 新华网时评 6 篇新文章（官方评价体 12 段——与训练"评论 87 段"完全不同源）；AI 侧=全新 prompt 生成（与训练/已有测试不同——prompt 全记录于 manifest）
- **白话叙事（20 对）**：sent_proj 人类 0.890 vs AI 0.811——差 +0.079——**d 1.33（95%CI 0.77~2.02——p<0.001——方向 12 正/1 反）**；l7_adj d 1.01（p=0.003）；word_adj d 0.91（p=0.007）
  - **判定：现有结论非训练记忆**（完全未入训仍显著分离——方向一致）——数值低于 L1（d 1.33 vs 3.62）归因风格差异（特稿自述 vs 网文小说——判别器风格鲁棒性因素）——预设通过标准（方向一致+d>1.5）中方向一致通过、效应量 d 1.33 未达 1.5——如实报告
- **官方评价体（12 对）**：sent_proj 差 0.000——**全维归零复现**——新华时评完全未入训仍不可判——**边界结论独立验证**（非训练记忆——是文本类型固有）
- **配对方式说明（严格配对）**：白话域=同一生活问题（人类原文主题）→AI 按该问题第一人称口述生成（同主题/同体裁/同长度）；时评域=新华时评原文段落→AI 按该段论点生成严肃评论（同论点/同体裁/同长度）

#### 4.5.2 循环性实证（⑦——指纹 vs 纯 bge——独立集）
- 白话域：判别器指纹投影 AUC 0.225（d 1.23）vs **纯 bge 512 投影 AUC 0.241（d 0.93）——差异 p=0.90（DeLong bootstrap 配对检验——无显著差异）**
- 时评域：指纹 AUC 0.417 vs bge 0.354（p=0.52——无显著差异）
- **结论：投影一致性信号存在于基础编码器（bge）空间中——判别器只是压缩维度（64 vs 512——性能相当）——指纹不依赖判别器训练目标——循环性质疑回应**（判别器从未被训练去最大化段内投影一致性——该度量独立于其输出）

#### 4.5.3 双模型对比（④——DeepSeek-v4-flash vs Qwen-plus——独立集 32 对）
- **白话域**：sent_proj DS d 1.33 / **Qwen d 1.93**（两模型都显著分离——方向一致）——l7_adj DS 1.01/Qwen 1.37——模型间差异显著（DS vs Qwen p=0.004——Qwen 白话漂移更大）——entropy DS 无差 vs Qwen d -2.01（p<0.001——Qwen 套话堆砌）
- **官方评价体**：两模型全维归零（Qwen sent_proj 0.919 vs 人类 0.931——无差）——**边界是模型无关的**
- **结论：判别体系对两个不同架构模型都有效——漂移程度模型依赖（方向一致）——边界结论跨模型稳健**

#### 4.5.4 外部锚核心（②——锚口径对称性检验——关键）
- **prompt 锚（不对称口径——AI 用生成 prompt 文本作锚/人类用自身首句）**：白话域 d 1.97（p<0.001）
- **对称锚（双方均用自身首句——对自身起始点的保持能力）**：白话域 **d 0.50（p=0.14——不显著——方向 9 正/5 反）**——官方评价体 d -0.41（不显著）
- **诚实结论**：外部锚核心判别力**部分依赖锚口径**——prompt 锚与正文的语义距离天然大于首句与正文——d 1.97 的口径伪影——**对称口径下不显著**——段内均值核心（d 1.23）为稳健主口径——"围绕全局意图组织"假说在单段配对层面**未获对称口径支持**——但长文档实验（对称首段锚）提供独立证据（4.5.5）

#### 4.5.5 长文档实验（③——3 篇 AI 长文 vs 天行健前 6 章人类对照——章节级 6v6）

**边界声明（防过度声称——重要）**：
1. **相关性≠因果**：维度与语言特征的相关（73 对）不能直接说"指纹由这些特征构成"——指纹是压缩表示——相关是伴随关系非构成关系；
2. **回归系数≈0**：投影一致性←表层特征的标准化回归系数接近 0（人类内/AI 内）——**表层机制不能完全解释投影一致性**——不能说"主题词重复就是指纹投影的全部"——主题词/指代等是显著伴随机制——投影一致性编码更深层组织；
3. **样本量有限**：独立集虽未入训但规模仍小（白话叙事 20 对）——统计功效需注意——效应量方向一致但幅度需更大样本稳定；
4. **语言特定性**：目前仅中文——主题词重复、指代方式等机制可能受语言类型影响（如英语的显性指代更多）——跨语言验证已列入后续工作。

**§4.5.10 方法声明（英文侧度量——逻辑边界——防止过度声称）**：

> 英文侧使用嵌入级度量（纯 BGE 投影），与中文判别器指纹在几何操作上同构（同为归一化嵌入→核心投影→一致性指标）。根据 §4.5.2 循环性实证，判别器指纹与纯 BGE 投影判别力无显著差异（p=0.90），因此英文嵌入级度量可视为与中文指纹在概念上等价的可操作版本。

- 中英两侧**测的不是同一个实体**：中文=判别器中间层 64 维激活（bge-small-zh-v1.5 + ParaDiscNN）；英文=bge-small-en-v1.5 句嵌入 512 维（实测 384 维）恒等映射——判别器纯中文训练不可迁移（形状兼容但语义 OOD）——英文侧代码路径接触不到判别器——**"跨语言一致"的正确表述是"在几何操作同构的等价可操作版本下结论一致"——不声称"复现了同一现象"**；
- **语料时代/体裁偏差（必须标注）**：中文人类=20-21 世纪现代小说 vs 英文人类=19 世纪经典——体裁与时代差异可能影响"意图保持"基线（19 世纪长篇章节独立性强/多线叙事）——**不声称"人类基线跨语言等同"**——只报告"中英文均呈现 AI 贴附不足（人类>AI，段内均值核心口径）——幅度差异可能受语料时代/体裁影响——可比性限定为方向与相对结构。

2. **Kalman 观测模型失配实锤（K1/K2）**：innovation 强负自相关（-0.85）+ 方差超设定 7-26 倍——**句元级自指观测与匀速漂移模型不相容**——这是 pid_kalman（-1%）的数学根因——外部核心观测（ext）缓解但 R 失配仍在；
3. **预测精度路径已打通（P1/P3）**：S2 r=0.15 的根因是 **Kalman 先验语义与收敛问题**（trace 读上一段 step 的 predict 输出/ x0=0.85 常量主导）**非段间不可预测**——滞后结构预测 r≈0.68 远超注入可行性门槛（r≥0.5）——**推理期意图可预测性成立，改进方向=直接用上一段实测作先验**；
4. **注入增益受方向精度主导（M1 定性——实验修正数量级）**：方向误差扫描显示增益随 cosθ 单调下降且低精度区（cosθ<0.3）增益坍缩——但**恒等式桥接失败**（指纹空间非均匀随机方向）——数量级以实验为准（§4.6.5：38-55%）。

#### 4.6.5 虚拟 token 意图注入实验（v0.73——18 runs——通道层新证据）

**设计**：学习映射层 MLP（64 维指纹→896 维 Qwen2.5-0.5B 嵌入空间——54,331 句元对训练——held-out 余弦 0.580 vs 均值基线 0.501/随机 -0.039——映射可行但边际增益温和）→ 意图指纹经 φ 映射为**虚拟 token** 注入输入序列段首（模型原生控制 token 模式）→ 范数校准到真实 token 嵌入尺度（0.46——**端部注入实测病态：V 注意力主导致主题词循环——段首注入实测正常**）。三档方向：vt_kalman（段内句元指纹 EMA 运行核心——在线意图估计）/ vt_ext（prompt 句元核心——可实现锚）/ vt_oracle（none 同 prompt/seed 文本的全篇核心——lookahead oracle）。

**结果**（3 prompt × 2 seed 配对 none——seg2+3 窗口——oracle 参照 Δ+0.09 同 §4.6.1）：

| 条件 | 注入方向 | win sent_proj | Δ vs none | 配对 p | oracle % |
|---|---|---|---|---|---|
| none | — | 0.8522 | — | — | 0 |
| vt_kalman | 段内 EMA 运行核心 | 0.8862 | +0.0340 | 0.181 | **38%** |
| vt_ext | prompt 句元核心 | 0.8966 | +0.0445 | 0.108 | **49%** |
| vt_oracle | none 全篇核心（lookahead） | 0.9020 | +0.0499 | 0.068 | **55%** |

**推导结论（§4.6.5——通道层新证据）**：

1. **虚拟 token 通道真实可行且优于 logits 通道（新证据）**：vt_oracle 55%（>50 判据）——冻结 0.5B 上段首注入+范数校准+MLP 映射**工作正常且可传意图**；同方向下 vt_ext（49%）**高于 pid_kalman_ext（33%）16 点**——**通道效率提升真实存在**（注入载体从 logits 偏置换成输入序列控制 token）；
2. **方向精度梯度（核心发现）**：38% < 49% < 55%（在线 EMA < prompt 锚 < 全篇 oracle）——**方向误差主导增益的定性结论被实验直接验证**——模块 3 的模拟数量级（κ=-2.2 负增益预测）被证伪（恒等式不成立）——**预注册降级预案"以实测为准"生效**；
3. **训练期接口的实证支撑**：映射层 MLP 是现成可训练组件——冻结注入可行但方向受判别器观测口径限制（在线估计 38%）——**训练期联合优化（φ 与 LM 同步训练——消除 OOD 注入问题）是语义层最终出路的新接口形式**（§5.6）。

**组合实验：vt 注入 + 句级种子 + beam5（v0.73-2——6 runs——oracle 117% 新最高点）**：把虚拟 token 注入（V=prompt 核心）与推理期最优形态（句级种子 12 token β=0.5 + 段 2/3 beam5）叠加：

| 条件 | win sent_proj | Δ vs none | 配对 p | oracle % | l7_adj |
|---|---|---|---|---|---|
| none | 0.8517 | — | — | 0 | 0.708 |
| sentence_seed_beam | 0.9256 | +0.0740 | 0.001 | 82% | 0.841 |
| **vt_seed_beam** | **0.9573** | **+0.1052** | **0.010** | **117%** | **0.893** |

**组合判定**：①**叠加成功**——vs sentence_seed_beam Δ=+0.0353（p=0.090 边缘）——vt 通道在种子+beam 之上再增 +35 点 oracle（82%→117%）——**推理期干预谱系新最高点（种子锚定起点 + vt 通道持续指向 + beam 评估选优三层叠加）**；②**同质化代价并表**——l7_adj 0.893（整体 Δl7÷Δsent=1.76 > 1.5——beam 选优固有倾向）——但 **vt 通道的边际增量是干净的**（Δl7 增量 0.052/Δsent 增量 0.035=1.49 < 1.5——通道增量未触发同质化判据）。

**卡尔曼实现问题修复（v0.73-2——S2 r=0.15 归因+修正）**：三证据钉死（①段开始读旧 x_pred——step 内 predict 是"预测上一段"的先验——缺一步 predict(上一段后验)②收敛慢 x0 主导③R 失配 7-26 倍）——修复：`Kalman2D.predict()` 段开始推进后验——**实跑复算：r 0.147→0.389（seg2/3 0.468——2.6-3 倍提升）**——接近 P1 门槛 0.5（离线标准语义同 z 重放 0.509）——策略分配从"段 2 恒 strong（强制 beam5）"变为自适应（strong 7/weak 3/free 8——预测达标免 beam——**效率联动**）——**预测精度路径闭环：Kalman 修复 + 滞后先验（0.605 更高——最佳=两者混合）**。

**无 beam 测试（v0.73-3——24 runs——去掉最贵组件的效果判定）**：beam5 占组合成本 78%——去掉后靠种子+注入+卡尔曼门控能否保持效果：

**无 beam 结论（B1-B5）**：①**种子效应完全依赖 beam**（seed_only -1%——82% 中种子的贡献 ≈0——种子改变候选分布、beam 选优兑现——"最小干预原则"修正为"**种子+beam 是最小有效组合**"）；②**Kalman 预测门控是无 beam 最优**（46%——接近持续注入 vt_ext 49% 但只注入一半段——**"何时注入"比"注入什么"重要**——修正 Kalman 的预测精度（r 0.47）直接兑现为干预决策——0.34 秒/点效率全谱系第二）；③**无法完全保持**——beam 净贡献 36 点 oracle（46% vs 82%）——**判别器评估（beam 选优）是无可替代的组件**——但单位时间产出无 beam 3 倍——**绝对质量 vs 单位时间产出的权衡定论**；④**vt_gate_beam（门控→{beam 开关, 注入强度}双自由度——待办①）**：Kalman 预测决定 beam 与注入（e_pred>0.05→beam5+强注入；>0.02→半注入；否则自由）——**oracle 103%（p=0.010 显著）——只比无条件组合（117%）低 14 点，但成本降 67%（38.6s vs 116.2s）、单位时间产出 2.7 倍（0.37 vs 0.99 秒/点）**——门控把 beam 从"无条件 2 段"压缩到"预测漂移段"——**预测驱动的资源分配 = 质量-成本最优平衡**——推理期干预最终形态建议：**种子 + Kalman 门控（beam/注入双自由度）+ vt 通道 = vt_gate_beam**；⑤**vt_seed 复述副作用归因**（待办②）："种子+V 持续注入（无 beam）"组合触发段 2/3 复述 prompt（17-25%）——beam 选优自动过滤（vt_seed_beam 0%）——**门控形态天然规避（vt_kalman_gate 0%）**。

## 5. 讨论

### 5.1 意图锚点假说的验证程度

**强支持（现代叙事域）**：人类投影 0.96±0.03（稳定贴核心）vs AI 0.79-0.84（显著漂移）——方向一致性 18/20（投影）与 19/20（相邻句元）正向——三主指标 d 均 >2.7——这是"人类围绕意图核心组织语言、AI 缺乏全局锚点"的直接证据。

**限定（文体依赖）**：人类贴核心程度呈文体依赖——叙事 0.96/时评 0.92/天行健 0.85/文言 0.75。文言域人类指纹全体落低饱和区（0.73-0.77——std 0.014——「指纹空间饱和」——语言压缩使指纹失去区分间隔）——判别不可行。官方评价体人类自身高度模式化（0.92——"现象+举措+意义"模板句）——人类与 AI 的模式化程度相当。

**结论**：假说适用范围="围绕单一意图核心的自由创作型写作"。

### 5.2 核心发现一：存在可计算的能力子域「长程意图保持」

**定义（精确化）**：文本生成过程中，局部单元（句/词）围绕全局意图核心组织的稳定性——可分解为"锚定强度"（贴核心程度——sent_proj/l7_adj/word_proj）与"锚定维持"（生成过程中的漂移——traj/方向一致性）。**"长程"=从初始意图设定到整个生成过程结束的全时段——而非文本尾部衰减**——实测依据：archives 6 章 AI 轨迹无长程衰退（+0.006/章）——AI 的意图缺陷不在"越写越散"，而在"局部-全局组织"的锚定强度不足（句元级投影 0.79-0.84 vs 人类 0.96）。

**数据论证（逐条）**：

1. **锚定强度人机分离**（实验一 L1）：sent_proj 人类 0.964 vs AI 0.837（差 0.127——d 3.62）；l7_adj 0.919 vs 0.677（差 0.242——d 3.73）——AI 生成时局部单元围绕核心的收敛明显弱于人类。
2. **方向一致性**（4.1.2）：叙事域句元投影 18/20、相邻句元 19/20 对人类恒高——非个别样本——系统性质。
3. **锚定维持（漂移可测）**：traj 人类 0.033 vs AI 0.130（3.9×）；多段连续域 AI 段内 std 0.116-0.133 vs 人类 0.049-0.091（2-4×）。
4. **「锚定效应」（关键证据——实验三）**：文言输入原文 AI 贴住（AUC 0.52——sent_proj 差仅 0.002）vs 文言自由创作漂移（0.80——差 0.031）——**AI 有能力跟随外部锚（给原文就贴住）——缺乏的是"自发锚定"（自由生成时无全局意图可跟随）**——这直接支持"大模型靠局部语言锚定、缺全局思维"的判断。
5. **多段连续独立验证**（实验三）：白话自由仿写 1.00/0.88——白话输入原文续写 0.94——AI 在连续生成场景中同样无法自发保持人类级锚定。
**长文档探索**（4.5.5——n=3 AI vs 天行健 6 章人类对照——章节级 6v6——探索性）：对称首段锚口径下，3 篇 AI 长文（4298-8587 字——其中 archives 6 章由叙事写作工作流 awesome-novel skill 生成）首末段投影差 0.078-0.154（人类对照 0.028——3-5.5 倍）——章节级 archives vs 天行健前 6 章：AI 各章整体低 0.06-0.09——趋势一致需更大规模验证。
**篇核心配对级证据**（4.5.6——35 组——强证据）：锚=被指向的核心思想（全篇句元指向中心——非句首）——白话域 d 2.04-2.09（p<0.001——19正/0反）——**"全局锚定缺失"获配对级支持**——与段内均值核心（d 2.37）同量级——跨段指向一致性可测——长文档章节级：AI 各章整体贴附低（差 0.06-0.09）但无章间衰减（与首锚口径的衰减模式互补——综合为"贴附不足"）。
**锚口径限定（诚实）**：单段配对层面，外部锚核心（prompt 锚）的判别力在对称口径（双方自身首句）下不显著（d 1.97→0.50——4.5.4）——**围绕全局意图组织假说在单段层面的支持依赖段内均值核心口径（d 1.23 独立集）与长文档首段锚口径（对称）**——不声称 prompt 锚口径的判别优势。

### 5.3 核心发现二：「锚定效应」与「自由度主线」

**锚定效应（实验三文言对照——用户直觉验证）**：输入原文（外部锚）→ AI 指纹贴住人类（0.52——方向交错——分辨不出）；不输入原文自由创作 → AI 指纹暴露（0.80——AI 5/5 全检出）。**输入原文是文言 AI 最难的分辨场景——AI 贴核心的能力依赖外部供给**。

**自由度主线（全部数据收敛的规律）**：可判性随"生成自由度"单调变化——自由创作（1.00/0.88）> 白话输入原文续写（0.94）> 文言自由（0.80）> 文言输入原文（0.52）> 同内容改写（0.63）> 官方评价体（0.16）。**外部锚定与格式模板是 AI 的「意图拐杖」——拐杖越多越难判别——这本身是对意图锚点假说的侧证**（AI 贴核心的能力依赖外部供给——缺少自发全局意图锚定）。

**白话 vs 文言的锚定差异**：白话输入原文仍可分辨（0.94）——说明"输入原文"的锚定保护在白话域不成立（AI 续写时指纹照常漂移）——锚定效应强度与语言压缩程度相关（文言域外部锚覆盖了指纹差异——白话域覆盖不了）。

### 5.4 边界域的三种失效机理（难以判别的原因——逐域分析）

三个低判别域（官方评价体 0.16/同内容改写 0.63/文言输入原文 0.52）失效机理不同——分类如下：

**① 模板型失效（官方评价体——AUC 0.16——完全不可判）**
- 数据：各维度差值 ≤0.025 且全部不显著（词熵差值 0.044 也无显著差异）——方向 2 正/2 反/6 无差——**AUC 0.16 甚至反向（AI 生成评论比人类时评更"贴核心"：句元投影 0.934 vs 0.926——AI 结构更整齐）**
- 机理：官方评价体是**规则驱动写作**（"现象+举措+意义"八股式结构）——人类写作时自身就在模板锚定——句元投影只有 0.926（vs 小说 0.96——人类自己就不"贴核心"）——**AI 与人类的生成机制在此域趋同（都是模板填充）**——意图锚点假说的前提（自由组织语言）不成立——判别自然失效
- 关键判断：这不是"AI 写得像人"——是**"人类写得像 AI"**（模式化程度相当——双向趋同）

**② 锚定型失效（同内容改写——AUC 0.63）**
- 数据：sent_proj 差 0.006（人类 0.823 vs AI 0.829——完全重合）——方向 1 正/1 反/8 无差——修正区间错位后仍无分离
- 机理：**双重锚定**——内容锚（输入原文——语义完全锁定）+ 风格锚（要求同风格）——AI 生成自由度趋近于零——无需自发意图组织（跟随原文即可）——指纹没有漂移空间
- 与"白话输入原文续写"（0.94——可分）的关键对照：续写=输入锚→自由展开（AI 自创内容——漂移暴露）；改写=重写同一段（内容锁定——无漂移空间）——**锚定强度差异：改写 > 续写——内容锁定程度决定判别力**

**③ 饱和型失效（文言输入原文——AUC 0.52）**
- 数据：sent_proj 差 0.002（0.794 vs 0.796——五维归零）——entropy d+2.44 经截断验证为长度伪影（4.4）
- 机理：**双向挤压**——①外部锚定（输入原文复述——AI 贴住人类）②**指纹空间饱和**（文言人类指纹全体落 0.73-0.77 低饱和区——std 0.014——语言高度浓缩：单字多义/省略/典故——句元间投影差异被压缩——判别间隔消失）——人类低饱和 + AI 被锚定贴住——两边贴着同一个点
- 佐证：文言自由创作（无锚）AUC 回升至 0.80——但投影差仍只有 0.031（vs 白话 0.093-0.158）——**饱和限制使文言域判别上限封顶**

**三类型与自由度主线的关系**：模板型=人类侧自由度本身低（人类=AI 都模板化）；锚定型=AI 侧自由度被外部约束锁死；饱和型=指纹空间承载不了差异——三种机理共同构成"边界域"的完整解释——**判别体系的适用条件可精确表述为："自由组织语言 + 指纹空间有区分间隔"**。

### 5.5 定位：与主流方案的配合与对比

| 方案 | 优点 | 缺点 | 本系统（数据对照） |
|---|---|---|---|
| 数字水印 | 精确/不可绕过 | 需模型方配合——开放域不可用 | 开放域可用（判别器独立部署）——但受边界域限制 |
| 统计/风格特征（GPTZero 等） | 部署简单 | 易被改写绕过（同义词替换） | 结构级指纹（l7_adj——相邻句元方向）对局部改词鲁棒（v0.60 实测：局部改词不影响 l7——md 换词指纹完全无效——AUC 0.953 保持） |
| 神经网络分类器 | 端到端 | 黑盒——跨域泛化差——单域测试 | 可解释（定位漂移层级/位置）；跨域边界实测（6 域地图） |
| 混合方法 | 综合 | 依赖各组件 | **配合定位**：本系统可作混合架构中的"结构诊断层"——其他组件给"是否"——本系统给"哪里/为什么" |

**配合方式（客观）**：检测场景中本系统定位为"第二双眼睛"——与其他方案互补而非替代——优势场景=现代白话叙事类（小说/自述/创作型文本——AUC 0.88-1.00）；不覆盖场景=官方评价体/改写/文言复述（已诚实标出——可组合其他方案兜底）。

### 5.6 启示：训练期与推理期的意图锚点应用（对 AI 幻觉与长程一致性的可能改善）

**推理期——漂移监测**：
- 数据基础：traj 人类 0.033-0.066 vs AI 0.104-0.132（1.7-3.9× 可测——各域实测）；逐段 sent_proj 实时可得（单段计算 <1s CPU）。
- 应用：生成过程中实时计算当前段指纹与初始意图核心的投影——低于人类基线（0.94 级）→ 标记漂移段 → 触发重生成/回溯校准。
- **客观标注**：机制可行性由数据支持（漂移可测且方向稳定）；端到端"回溯改善输出质量"的实验**未做**——是推断。

**训练期——意图锚点损失**：
- 数据基础：人类段内句元余弦 0.889（龙族）——AI 低；l7_adj 人类 0.92 vs AI 0.68——"同指向"是人类的可量化特征。
- 应用：将指纹轨迹作为辅助正则项（约束第 k 段隐状态与首段意图核心保持高余弦）或过程奖励（traj 超标即惩罚——补 RLHF 只监督最终结果的缺口）。
- **客观标注**：本系统判别器冻结可作损失函数的**特征提取器**（64 维——轻量——CPU 可跑）；但"嵌入训练后确实改善长程一致性"**未验证**——需专门的训练实验——本文只给出测量端到约束端的可行接口。

**对幻觉的讨论（客观）**：幻觉的成因多元（数据污染/解码随机/知识缺失）——"意图漂移"只是其中一类（长上下文中的语义迷失）。本文数据支持"意图漂移可测"（多段连续 35 组——AI 段内组织漂移显著）；因此**意图锚点约束可能缓解"语义迷失型"幻觉**——但不声称解决全部幻觉。这是有限、可检验的陈述。

**意图锚点正则的向量空间预演（v0.67-2——偏置修正模拟——oracle 上限估计）**：在真实训练实验前，先用向量空间模拟"上层封装对下层池的影响"（用户实验设计）：对 AI 长文本逐句 64 维指纹序列 v_i 做偏置修正 v_i' = v_i + α·(I_target − v_i)（单位球线性插值——α=0/0.3/0.5——I_target 取首 3 句锚或篇核心两口径——数据 data/bilingual_test/bias_correction_sim.json + fig_bias_correction.png——4 篇：AI-DS 短/长 + AI-Qwen + 人类对照）：

| 口径 | 指标 | AI 原始（α=0） | α=0.3 | α=0.5 | 人类对照原始 |

| 篇核心 | sent_proj | 0.817-0.869 | **0.905-0.931** | 0.952-0.966 | 0.902 |

**量化结论（诚实框架）**：
1. **α≈0.3 即达人类基线**：AI sent_proj 0.817-0.869 → 0.905-0.931 ≈ 人类原始 0.902——**把每句指纹往全局核心拽 ~30% 就达到人类贴附水平**——这是"意图锚点损失"强度需求的首个量化估计；
2. **traj 系统性减半**（α=0.3 再减半至 α=0.5）——轨迹粘合（相邻句跳跃）显著改善——与"AI 不平滑更参差"的既有发现直接对应；
3. **长程衰减被遏制**：首 3 句锚口径首末段差收窄 74-75%（α=0.5）——"AI 贴着开头快速衰减"的模式被偏置修正逆转——**说明长程衰减在向量空间上可通过"持续指向核心"的约束消除**；
4. **多样性代价（必须报告）**：l7_adj 0.68 → 0.91（α=0.5）——相邻句指纹余弦逼近 0.9+——**句子高度同质化（语义塌缩风险）**——fp 方差缩小 ~10%——修正过度（α→1）所有句塌缩为核心点——**α 甜点区约 0.2-0.4（提升贴附而不牺牲过多多样性）**——真实训练中"主题词保持"类正则的退化模式（重复/套话）正是此代价的语言表现；
5. **oracle 上限声明（关键）**：本模拟 I_target 取**已知全篇后的理想终点**（篇核心/首 3 句）——真实训练正则无未来信息（只能自指当前段落/滑动窗口的局部均值核心）——因此 **α≈0.3 是理想下限（oracle 红利）**——真实可教的偏置强度 ≥ 此值——差距=全局 oracle 红利——训练实验应预期更高正则强度或学习式核心估计。

**训练干预实证（v0.68——负结果但方向性证据——回答"上层封装引导 token 概率是否可行"）**：将上述模拟落到真实生成循环——本地 Qwen2.5-0.5B（MX570 2GB——0.93GB fp16）逐 token 手动采样——判别器作监测器每段实时算 sent_proj（阈值 0.85）——低于阈值触发"主题词保持"采样规则（**概率层加权——不改 logits**：top-50 候选内命中前段主题词（jieba 高频实义词 top-5）→ 概率 ×(1+β)——β=0.3/0.5）——27 runs（3 条件×3 prompt×3 seed——同 prompt 同 seed 配对可比——全量数据 data/training_intervention/）：

| 对比（vs 无引导——seg2+3 窗口） | Δsent_proj | d | p（单侧） | 配对 p | 主题词密度 d/p | Δl7÷Δsent |
|---|---|---|---|---|---|---|
| β=0.3 | +0.022 | +0.28 | 0.278 | **0.093** | +0.45（p=0.359） | 1.6 |
| β=0.5 | +0.015 | +0.20 | 0.340 | 0.125 | +0.23（p=0.629） | 2.5 |

**诚实结论（负结果框架——信息完整）**：
1. **判别器监测器工作精准（强支持）**：trigger 率 67%——触发段全部为真实低投影段（0.76-0.85）——未触发段（0.90-0.98）全部高质量——"何时引导"判别准确；
2. **概率层弱干预不达标（主判据未达——p<0.05 且 d≥0.5 双条件不满足）**：三个独立证据（均值差/配对差 p=0.093/主题词密度 d=+0.45）全部指向正方向但不显著——**方向性证据、非显著提升**；
3. **多样性代价超收益**（Δl7÷Δsent = 1.6/2.5 > 1.5——"同质化换投影"判据触发）：概率层加成拉向机械重复（案例：match 42% 但 sent_proj 未动——主题词重复未组织化）；
4. **oracle 红利实测 ~75%**：模拟预期 Δsent_proj ≈+0.09（α=0.3 达人类基线）——真实引导仅 +0.022——**无 oracle 信息的真实可达占比约 25%**——滑动窗口自指核心 + 概率层弱干预够不到 oracle 效果；
5. **0.5B 弱模型混淆**：生成质量参差（复读/主题词漂移）——相对对比仍有效但统计力受限（n=9/条件）。

**实证回答**：判别器作为上层封装的**监测器强支持**（精准识别漂移段）；作为**引导器——概率层弱干预（不改 logits）不足以显著提升贴核心——定义了干预强度下界**——下一步候选：①logits 级加权（把主题词 token 直接拉入候选）②训练级正则（判别器指纹作损失项——梯度回传——本系统判别器冻结可作特征提取器——64 维轻量）——负结果本身即"需要更强手段"的实证依据。

**logits 级加权（v0.68-2——判别层插入数学方法的实证选择）**：将引导升级为**全词表加法偏置**（logits' = logits/T + β·g——g=主题词指示向量——top-k 之前——可"救回"主题词进入候选）——并实施结构性修正（用户指出）：**主题词锚改用"好段 buffer"（最近 sent_proj ≥ 阈值的段——稳定意图核心——防"漂移锁定"——避免第 2 段偏离后第 3 段沿用偏离主题词造成"局部收敛全局漂移"的虚假信号——无好段时回退 prompt 前 3 句主题词）**——21 新 runs（lg05 β=0.5 机制探针 9 + lg10 β=1.0 强度档 9 + lg_placebo 安慰剂 3——随机 token 同强度——控制"加法操作本身"混杂）——v0.68 的 27 runs 只读复用——完整数据 data/training_intervention/（48 runs 总计）：

| 条件（vs 无引导） | Δsent_proj | d | p（单侧） | 配对 p | Δl7÷Δsent | oracle 占比 |
|---|---|---|---|---|---|---|
| 概率 β=0.3（v0.68） | +0.022 | +0.28 | 0.278 | 0.093 | 1.6 | 25% |
| 概率 β=0.5（v0.68） | +0.015 | +0.20 | 0.340 | 0.125 | 2.5 | 17% |
| **logits β=1.0（本轮）** | **+0.036** | **+0.51** | 0.148 | **0.017** | 2.1 | **40%** |
| 安慰剂（随机 token） | -0.006 | -0.07 | 0.536 | — | 0.4 | -6% |

**结论（判据决策树执行——诚实）**：
1. **logits 加法偏置是当前谱系最合适的数学方法**：lg10 配对级显著（p=0.017）+ d=+0.51——效果为概率层的 2-3 倍——oracle 占比 25%→40%——**"上层封装引导"从方向性证据升级为配对级证据**（独立样本 p=0.148 未达 0.05——n=9 功效不足——报告配对为主判据）；
2. **提升是强度驱动非机制驱动**（机制探针 lg05≈0——β=0.5 只比 b05 强 10% 但无增益——rescue 4.6%）：候选集访问在纯偏置下救不回主题词（主题词 token 距 top-50 太远）——概率层 b03 的 +0.022 来自候选内加权本身；
3. **top-p 交互损耗**（B2 负结果发现）：偏置救回的 token 被 top-p 裁掉（22.6 次/run vs 0）——v0.68-3 改进点=top-p 后并集救回；
4. **安慰剂干净**（lg_placebo d=-0.07 p=0.93）——加法操作本身无混杂——提升全部可归因于主题词引导；
5. **家族上限**：β=1.0 达 oracle 40%——"主题词保持"操作本身的天花板——人类贴核心=主题组织（话题链）而非简单词重复——更强干预需在词重复之上引入组织约束（beam 重排/训练级正则——判别器指纹作损失项接口 §5.6 已声明）。

**判别器向量干预 token 概率池——四路径谱系（架构定位——用户分析定稿）与 v0.68-3 实证**：

| 路径 | 数学形式 | 实证状态 |
|---|---|---|
| 路径1：向量→标量→干预 | s=sent_proj(f,core)→阈值触发主题词规则 | **✓ 已证（lg10 配对 p=0.017——d=0.51）** |
| 路径2：向量→梯度→Logits | Δlogits=∇_f s(h)（PPLM 式） | 未做——段级量无 token 级可微代理+成本不可控 |
| 路径3：向量→条件→Logits | logits'=logits+β·g(f)（需训 g: R^64→R^V） | **数据判定不优先**（lg05≈0：瓶颈不在候选集访问——若仍输出主题词偏置不会突破上限） |
| **路径4：向量→重排→选优** | f(cand₁..cand_N)→选 sent_proj 最高 | **✓ 本轮验证——当前最强** |

**v0.68-3 实证（66 runs 总计——完整数据 data/training_intervention/）**：
1. **top-p 并集救回（lg10u）——U1 负结果**：lg10u−lg10 配对差分 -0.0185——被 top-p 裁掉的主题词 token 是"偏置后概率仍低"的尾部候选——强制加入候选稀释了保留集概率质量——**top-p 损耗不是瓶颈（被裁 token 本应被裁）——并集救回方向错误——消除损耗假设被数据否决**；
2. **Beam 重排（beam5——路径 4）——重大正结果**：触发段生成 5 候选（同源采样随机性）→ 判别器选 sent_proj 最高——**Δsent_proj +0.046 / d=+0.68 / 配对 p=0.006（全谱系最显著）——oracle 占比 51%——首破 50% 预注册线**——判别器评估能力（组织级筛选）超过词重复生成能力（主题词保持 +0.036/40%）——**验证"路径 4 是最大价值"的架构判断**；
3. **诚实限制（必标）**：①同源候选（同一前缀采样随机性——未引入不同生成策略）——51% 是同源选优上限——异源候选（不同 temperature/top-p/改写模板）可能更高 ②**语义验证缺失（风险 4 确认）**：抽查被选段——判别器选出高投影段含机械重复内容（0.5B 模型对话循环）——"beam 选优基于判别器投影未做语义验证"——高投影≠高质量——l7_adj 0.785（同质化）——下一步需在选优中加入语义多样性约束 ③0.5B 弱模型混淆。

**最终干预谱系（66 runs——Δsent_proj/配对 p/oracle）**：概率层 +0.015-0.022（0.093-0.125/17-25%）→ logits β=1.0 +0.036（**0.017**/40%）→ 并集救回 +0.018（0.106/19%——负结果）→ **Beam 选优 +0.046（0.006/51%——最强）**——安慰剂 -0.006（无混杂）——**判别器作为上层封装的完整实证：监测（触发精准）→ 规则（logits 偏置——配对显著）→ 评估（beam 选优——最强）——"上层封装引导 token 概率"从架构假设升级为逐级实证的工程结论**——训练级正则（判别器指纹作损失项）仍是未验证的下一步候选。

**外部篇核心三层级干预（v0.68-4——93 runs——用户理论修正实证）**：用户指出自指篇核心（好段 buffer）的根本性逻辑漏洞——"以自己写过的东西为锚"是自我强化（自己定义标准自己当裁判）——非"外部稳定意图目标"——修正：篇级锚点必须来自外部（提示词锚定或人类篇核心——生成开始前一次性提取——意图核心全程稳定）。27 新 runs（t2_prompt=词级+外部 prompt 锚无 beam/t3_prompt=三层级+prompt 锚/t3_human=三层级+人类锚——完整数据 data/training_intervention/）：

| 判据（预注册） | 结果 | 判定 |
|---|---|---|
| P1 外部篇级增益 | t3_prompt vs beam5 配对 Δ=+0.0009（p=0.474） | **未达——外部篇级锚在句元级选优之上无额外增益**（match 8.5%——引导确实发生但未转化 sent_proj） |
| P3 外部 vs 自指（干净对照） | t2_prompt vs lg10 配对 Δ=-0.0089（0/9 正） | **未达——外部锚反而略低于自指锚**——"外部锚优于自指锚"假设被数据否决 |
| P4 代价 | t3_prompt Δl7÷Δsent=78.4 | ✗——同质化上升无收益 |
| P2 人类锚差距 | t3_human oracle 58%——但 match 2.6%（**引导空转边缘——58% 主要是 beam 选优 51% 贡献**）——题材混杂（人类文本=长篇幻想 vs 短题材） | 中间档但混杂——不代表人类锚上限 |

**诚实结论（决策树落点——推理期天花板确认）**：
1. **锚来源差异在 0.5B+主题词保持框架内不可分辨**（外部 vs 自指 Δ<0.01——P3 甚至反向）——**瓶颈在载体（词重复操作上限 40%）而非锚来源**——用户理论修正的逻辑正确性（外部目标符合意图保持定义）不因效果未达而改变——但"外部锚优于自指锚"的实证假设被否决；
2. **推理期干预全层级天花板确认**：beam 选优（51%）占满剩余空间——词级引导（任何锚来源）在其上叠加无效（P4 比值 78）——决策树"P1 不通过但 P5 通过→主题词匹配增加未转化 sent_proj（sent_proj 对外部锚不敏感）"+"推理期上限已到"；
3. **训练期转向依据强化**：推理期剩余差距（oracle 49%）无法由监测+规则+评估家族弥合——**外部锚的真正价值需在训练级载体验证（把"贴外部核心"作为训练目标——判别器指纹作损失项——§5.6 接口）**——"提示词锚作训练期廉价锚"待题材匹配的人类文本重测。

**三层级自指锚对照（v0.68-5——102 runs——锚来源定论）**：补齐三层级自指锚（t3_self——好段 buffer + beam5——与 t3_prompt/t3_human 同框架对比——配对窗口均值差）：**t3_self−beam5 = +0.0055（未达 P1 的 0.02 阈值——自指词级引导在 beam 之上增益微小）——t3_self−t3_prompt = +0.0046 / t3_self−t3_human = -0.0007（锚来源三者差异 <0.005——不可分辨）**——自指 match 率最高（11.5% vs prompt 8.5% vs human 2.6%——主题词与生成内容同源）但未转化为 sent_proj 增益——**"外部锚优于自指锚"假设在词级（P3）与三层级（t3_self vs t3_prompt）两个层面均被数据否决——瓶颈确证在载体（词重复操作上限）与 beam 之上叠加空间（≤0.006）而非锚来源**——推理期天花板（beam 51% oracle）与锚来源无关——外部锚价值保留于训练级载体验证。

**Kalman+PID 闭环控制（v0.69——111 runs——推理期终极边界测试）**：将"层级向量反向传递"升级为控制论闭环（用户方案）——句元级 Kalman 状态估计（[intent, drift]——平滑 x_est + 先验预测 x_pred 前馈）+ 四层级 PID（篇幅级 Ki 积分/段落级 Kp 比例/句元级 Kd 微分——β(t)=clamp(Kp·e+Ki·∫e+Kd·de+α_feed·e_pred, 0, 2.0)——词级执行器）——9 runs（111 总计——完整数据 data/training_intervention/fig_pid_kalman_trace.png + manifest）：

**K1-K4 判定（预注册）**：K1 **未达且显著负向**（vs beam5 Δ=-0.047/d=-0.70/配对 p=0.021——vs none oracle -1%）；K2 判据失效（负分母）；K3 未达（traj 0.094 vs lg10 0.088）；K4 通过（26/27 段闭环运行——前馈工作）。

**归因（决策树——控制信号-输出响应检查——诚实）**：**β 分布均值 0.098/中位 0.000/84% 句元 β=0——控制几乎静默**——根因=**观测口径失配**：句元级观测 z 是"句元对动态段核心"的投影——**自指量天然高估**（句元与自身参与的均值核心投影上沿 ~1.0——x_est 范围 0.698-1.005）——误差 e=0.90−x_est 常为负——β 限幅 0——控制信号被系统性压低+段内"前松后紧"（Kalman 冷启动滞后——破坏一致性）——**判决：不是"载体受限"（β 从未充分激活）也不是"控制框架无效"（Kalman 单测收敛/PID 自适应/前馈——数学正确）——是"句元级自指观测不适用于闭环控制"的方法学发现**。

**终极边界测试结论**：推理期闭环控制在 0.5B 上——**控制框架可用（数学验证）但观测口径错误致干预静默**——结合 v0.68-4/5（外部锚无增益）——修正观测（外部核心投影）后预期仍受载体限制——**推理期干预方法空间已完整测绘（111 runs 谱系：概率层 17-25%→logits 静态 40%→beam 选优 51% 最强→闭环控制静默）——剩余差距（oracle ~49%）需训练期（判别器指纹作损失项——§5.6 接口）**。

**外部锚定闭环（v0.69-2——120 runs——观测口径修正与归因验证——推理期定论）**：将句元级观测 z 改为对 prompt 外部核心投影（消除自指高估）——9 新 runs（120 总计）：

| 指标 | 自指观测（v0.69） | 外部观测（v0.69-2） |
|---|---|---|
| 句元观测 z 均值 | ~0.9+（自指高估） | **0.702**（66% <0.85——误差信号真实） |

| 效果 | oracle -1% | **oracle 33%（配对 p=0.101 边缘——方向性）** |

**归因验证 ✓ 与最终定论**：
1. **"观测口径失配"归因完全验证**：外部观测消除自指高估——β 激活率 16%→72%——控制框架数学正确（此前静默是观测问题非框架问题）；
2. **但效果 oracle 33% < beam 选优 51%**——**β 均值 1.279（72% 激活——控制信号用到极限）仍未突破"主题词保持载体"上限**——动态控制再准也受执行器（词重复）限制——载体限制最终确证；
3. **推理期干预最终谱系（120 runs/13 条件）**：概率层 17-25% → logits 静态 40% → **beam 选优 51%（最强——判别器评估能力）** → 三层级 52-58%（无叠加）→ 闭环控制 33%（数学工作但载体受限）——**判别器的推理期价值收敛于监测（触发精准）与评估（beam 选优）——不在词级引导（任何形式：静态/动态/自指/外部）**——词级引导上限（40% oracle）是"词重复"载体的固有边界；
4. **训练期唯一出路**：剩余差距（oracle ~49%）需把"贴外部核心"作为训练目标（判别器指纹作损失项——§5.6 接口）——推理期干预方法空间完整测绘结论定稿（v0.69-2 时点——v0.73 系列通道层更新见 §4.6.5）。

**段落级 Kalman 前置预测与控制实验（v0.69-3——138 runs——种子引导效应重大发现）**：将 Kalman 换到段落级"前置预测"（用户方案）——预测下一段漂移 e_pred 后做策略分配（强 beam5/弱 beam3/自由）——并新增控制条件 beam5_ctl（段 1 同款 β=0.5 基线 + 段 2/3 无条件 beam5）分离归因——数学前提验证：段间漂移可预测（lag-1 自相关 +0.81/+0.91——漂移粘性 0.71）。

**归因分离（决定性）**：
1. **Kalman 策略分配无独立价值**：策略 vs 同基线控制配对差 **-0.0125（p=0.061）**——S1 表面通过（+0.0101/oracle 62%）是**段 1 基线混杂假象**——控制实验分离后策略价值≈0——"段间漂移可预测但策略分配不转化增益——beam 无条件选优已吸收全部空间——推理期再无增量"；
2. **种子段引导效应（重大新发现——v0.69-3 时点）**：段 1 用 β=0.5 概率层引导（vs 自由）→ 段 2/3（同 beam5）配对差 **+0.0226（p=0.046——显著——7/9 正）**——**oracle 51%→76%（+25%——超 beam5——超乐观预期 55-60%）**——段 1 自身差仅 +0.005（**效应主要在后继段——上下文延续**）——**词级引导的价值在"锚定起点"而非"逐段拉拽"**——统一解释 v0.68-2"引导发生未转化"（逐段即时转化弱——词重复载体限制）与种子效应（段间上下文延续强）——**当时最优形态 = 种子引导（开头 β=0.5）+ 评估选优（后续 beam5）= 76% oracle（演进：76%→82%（句级种子）→117%/103%（v0.73 vt 通道+门控——§4.6.5））**。

**推理期谱系（138 runs 时点——词级引导位置敏感定论——后续被 v0.73 系列超越）**：概率层逐段 17-25% → logits 静态 40% → beam 选优（自由种子）51% → Kalman 策略分配 62%（混杂后≈0——旧版实现）→ **种子引导+Beam 76%（当时最高）** → 闭环控制 33% ——**词级引导不是无用——是位置敏感（开头有效/逐段无效）——v0.73 系列进一步突破至 117%/103%（虚拟 token 通道+门控——§4.6.5——最高点演进：76%→82%→117%→103% 门控形态）**。

**句级种子（v0.69-4——147 runs——最小有效起点定论——82% 当时最高点——v0.73 系列超越至 117% 见 §4.6.5）**：将种子压缩至第 1 句前 12 token（β=0.5 概率层主题词引导——之后自由——段 2/3 beam5——与段级种子同结构）——诊断先行（第 1 句 vs 后续句 sent_proj 相关 r=+0.372——中等——预测弱潜力）：

| 条件 | oracle |
|---|---|
| beam5（自由基线） | 51% |
| 段级种子 + beam5 | 76% |
| **句级种子（12 token）+ beam5** | **82%** |

句级种子 vs 自由基线 **+0.0281（p=0.021 显著）**——vs 段级种子 +0.0055（不显著——方向正——句级 ≥ 段级）。

**定论（回答"级联效应的最小有效起点是多长"——v0.69-4 时点）**：**最小有效单位可压缩至句级（12 token——oracle 82%——v0.73 系列最高点演进见 §4.6.5：82%→117%）**——种子效应传导不靠"句质量"（诊断 r=0.372 低估）而靠"主题词锚定"（即使第 1 句自身投影未变——主题词分布改变后续延续方向）——**轻干预（12 token 后自由）优于整段持续引导（段级 76%）——"最小干预原则"：引导效力在锚定起点——干预越少越自然**（v0.68 逐段引导同质化教训的正面解）——**种子是 beam 的放大器而非独立机制（v0.73-3 无 beam 测试：纯种子 -1%——种子+beam 是最小有效组合）**。

**虚拟 token 注入通道（v0.73——§4.6.5 实验——通道层接口更新）**：学习映射层（MLP 64 维指纹→896 维嵌入空间）把意图状态映射为**虚拟 token 段首注入**——冻结模型上通道可行且**优于 logits 载体**（vt_ext 49% vs pid_kalman_ext 33%——+16 点）——受方向精度梯度约束（在线估计 38% < prompt 锚 49% < 全篇 oracle 55%）——**通道与既有形态叠加后超越此前最高点（vt_seed_beam 117%——§4.6.5）——最终推荐形态 vt_gate_beam（103%——成本降 67%）**——映射层本身是**训练期接口的新组件形式**：训练时 φ 与 LM 联合优化可消除冻结注入的 OOD 问题（范数校准 0.46 已实证必要——端部注入病态/段首注入正常）——判别器指纹经 φ 进入输入空间=训练期"贴核心"损失的**可微分通道**（§4.6.4 的 κ 方向梯度与 §4.6.5 的通道实证共同支撑）。

### 5.7 可检验推论：局部锚定与全局锚定的区分（用户建议——发展假说）

**区分两个锚定层级**：
- **局部锚定** = 段内句元围绕段内均值核心组织——**已由段内均值核心口径支持**（独立集 d 1.33-1.93——双模型一致——4.5.6）
- **全局锚定** = 跨段落围绕初始意图核心组织——**仅有探索性长文档证据**（n=3——首末差 3-5.5 倍——4.5.5）——外部锚对称口径下不显著（d 0.50——4.5.4）

**可检验推论**：如果模型能在每个局部段落内让句元围绕同一指纹方向组织（局部锚定），那么这种局部锚定能力可能**逐段累积**，使全文围绕一个稳定的全局意图核心（全局锚定）。然而——**局部锚定不自动保证全局锚定——它只是全局锚定的必要条件之一**。

**证据现状（诚实）**：本文数据支持**人类在局部锚定上显著强于 AI**（段内均值核心 d 1.33-1.93——双模型一致——独立集未入训仍成立）——但**外部锚对称口径下未观察到显著差异**——从局部锚定到全局锚定的推论**尚需进一步验证**。

**检验路径（完全验证的五步实验设计——未来工作）**：
①**扩大长文档样本**（最关键）：n≥10 篇人类（不同作者/体裁）vs 10 篇 AI（同 prompt 长度匹配）——首段锚投影衰减曲线——衰减斜率/首末差/方差比较——混合效应模型或 Mann-Whitney U——若 AI 衰减显著大于人类且方向一致 → "长程意图保持"差异获强证据；
②**外部锚核心重新操作化**：当前对称首句锚不显著可能因锚不够"全局"——改为**同一 prompt 嵌入作统一外部锚**（招募人类写作者按同一 prompt 创作 vs AI 同 prompt 生成——完全对称且真正"全局意图"）——若人类对 prompt 锚投影显著高于 AI → "缺乏全局意图锚定"直接支持；
③**训练干预实验**（局部→全局传导）：小模型（~1B）微调加**意图锚点正则**（约束隐状态与首段意图核心高余弦）——测训练前后局部锚定（段内均值核心投影）与全局锚定（长文档首锚衰减）——若局部提升且全局改善 → 传导机制成立——完整验证假说；
④**更多模型与多语言**：覆盖 3-4 个不同来源模型（GPT/Claude/Llama/Mistral 级）+ 英日等多语言——检验意图漂移跨模型跨语言一致 → 假说上升为普遍规律；
⑤**推理期漂移监测端到端验证**：生成过程中实时计算当前段与初始锚投影——低于阈值触发重生成/回溯——人工+自动评估对比——若显著改善长文本一致性与减少语义迷失型幻觉 → 应用价值实证。

**与假说的关系**：核心假说当前大模型靠局部语言锚定组织生成、缺乏自发全局意图锚定依然成立——但证据链中**局部锚定差异是坚实的**（强证据）——**全局锚定缺失部分有待加强**（探索性）——本节明确定义了两者——避免过度声称。

### 5.8 展望：AGI 自我反省与规划系统中的「意图稳定性」接口

**论证链（逐步——每步标数据/标注）**：
1. 自我反省与规划的必要条件之一是**长程意图保持**（对初始目标的持续指向）——常识前提。
2. 本文证明了**意图保持可计算**（指纹投影——64 维——CPU 可部署——判别器冻结零训练成本）——实测数据。
3. 本文证明了**AI 的意图保持缺陷可测**（漂移 d 1.7-5.5——方向一致性 95%+（18/20 与 19/20））——实测数据。
4. 推论（推断——未验证）：持续运行的智能体可监测"当前状态向量 vs 初始目标向量"的距离——超阈值自动触发自我校准/回溯——即把"反省"从启发式变为可度量的闭环。

**定位（收敛表述）**：本系统不是"AGI 自我反省/规划系统本身"——而是其中**"意图稳定性"这一可度量维度的可能接口**。自我反省/规划能力的形成还需目标表征、记忆检索、规划算法等组件——本文贡献的是其中可计算、可解释的度量环节。

**限定（诚实）**：①本文测的是文本层指纹——AGI 的意图状态还需行为/环境层融合；②小样本（每域 5-20 对）——量化精度需扩大验证；③"状态向量距离→自动校准"的闭环实验未做——这是本文数据可支撑的**研究方向**而非已验证结论。

### 5.9 样本量稳健性讨论（审稿争议预防）

本文每域样本 5-20 对——审稿人会质疑"5 组/域怎么能得出结论"。回应：**本文核心结论分两类——其可靠性由结论类型决定**：

1. **"大差"结论（叙事域强判别）**：可靠性支柱 = 效应量的**跨指标一致性**（L1 域三主指标 d 均 >2.7——sent_proj/l7_adj/word_proj）**+ 方向一致性**（95%+ 逐对符号稳定）+ 跨实验复现（单段 60 对与多段连续 35 组独立验证同向）——多个独立证据收敛于同一结论——小样本下此类"大差"仍可信。
2. **"归零"结论（边界域不可判别）**：可靠性支柱 = 全维度**归零一致性**（时评各维度差值 ≤0.025 且全部不显著——文言输入原文五维归零（除词熵外）——非单维度无差）——"全维度同时归零"比"某维度无差"稳健得多——若存在真实差异，不可能所有维度同时无差。
3. **中等差异（文言自由创作 d 0.8-1.2——AUC 0.80）**：此类结论**需更大样本复核**——已如实标注——不作为强结论。

**结论**：小样本下"大差"与"归零"比中等差异更可信——本文强结论均属前两类——中等差异已标注待复核。

**资源限制声明（样本量小的客观原因——诚实披露）**：本文样本量并非设计上限，而是**受限于作者个人资源**——①全部实验（判别器训练/指纹推理/数据分析）在**个人轻薄本（无 GPU 集群）上本地完成**；②AI 文本生成调用 DeepSeek API（个人自费——每域 5-20 对的预算约束）。**并非不想多样本测试**——实验管线（数据构建/生成/分析脚本）已全部保留且可复现（附录 A）——扩充样本仅需增加 API 调用与计算时间——中等效应（d 0.5-1.5）的复核与更大样本验证已列入后续工作。

3. 仅中文。
4. 已知边界：官方评价体（独立集复现归零——模型无关）/同内容改写/文言输入原文——不覆盖。
5. 段落级/篇章级无独立信号——四层级框架中该两级为聚合层——**但长文档实验（对称首段锚）显示外部锚口径下的长程衰减（4.5.5——探索性 n=3）**。
6. 训练/推理端应用（5.6/5.8）为推断——未做端到端验证。
7. 词熵需长度对齐。
8. **锚口径依赖**：外部锚核心的判别力在对称口径下不显著（4.5.4）——段内均值核心为稳健主口径——长文档首段锚为对称口径下的独立证据。

### 5.12 意图动力学引擎：从测量到模拟智能的架构构想（v0.74-5——新的最重要方向）

**核心理念**：传统自回归架构只有局部概率最大化一个驱动力——没有"为什么写这句话"的持续状态——生成必然表现为局部流畅全局散乱/主题漂移指代断裂/机械平坦缺乏节奏。本系统基于全部实测数据提出根本性架构判断：

> **智能的本质特征之一，是文本生成过程中存在一个可测量、可干预、可训练的"意图状态"——它不直接决定每一个词，但为所有词的选择提供引力场。**

意图状态通过判别器中间层 64 维指纹（尤其是未解释 11 维）几何化表示、轨迹化监测、动力学控制——全部组件已有实证基础。

#### 五条基于实证的架构定律

| 定律 | 内容 | 实证依据（本文数据） |
|---|---|---|
| **定律一：潜意识优先于表层控制** | 根意图不作逐句约束——作为背景势场——仅在轨迹偏离安全边界时轻微回拉 | 人类句元跳跃度显著大于 AI（d=+2.16）——**人类思想不是死贴核心而是在核心周围自由波动**——过度约束会让 AI 更平坦更机械 |
| **定律二：流动特征比静态特征更本质** | 思想流动的节奏/转折深度/耦合动态比单点投影值信息更多 | 句元级跳跃显著维度 **56/64** 远多于静态人机差异 **39/64**——转折峰谷陡度人类显著更高（d=+2.09——话题开合分明 vs 无鲜明起伏） |
| **定律三：维度极性必须区分对待** | 64 维非同质空间——正向组（人类组织组）鼓励波浪——负向组（AI 特征组）抑制机械摆动——**干预不能一刀切** | 未解释 11 维分组：**人类组织组**（dim10/11/34/46/48/59——人机 d 正向+人类波浪）vs **AI 特征组**（dim22/26/43/52/5——负向+AI 波动）——人类波浪出现在自己高激活维度上——AI 波动出现在自己高激活维度上 |
| **定律四：可解释性与判别力呈反比** | 判别器学到的深层信号恰是不可被表层语言特征线性解释的维度——**判别信号本体** | 已解释 42 维人机差异中位 d=0.32 vs 未解释 11 维 **0.53**——最强 10 维含 5 个未解释维度（dim58/55/59/34/46） |
| **定律五：信息流的"自由度"是新轴** | AI 的主题→指代转换更"机械确定"——人类更"自由不可预测"——信息论层面的量化轴 | 转移熵 TE(dim10→48) AI 0.0194 vs 人类 0.0124（d=-0.79 p=0.075）——AI 词重复后紧跟指代=字典式强关联——"人类自由 vs AI 机械"的信息论证据 |

#### 三层意图动力学引擎

**第一层：根意图势场（Root Intent Field）**——根意图=64 维（或 11 维核心子空间）固定向量 R——不直接干预生成——作为引力势场最低点——距离越近越"舒适"、越远势能越高——**仅在势能超阈值时触发修正**（对应实证：篇核心/外部核心锚——vt_ext/vt_oracle 的锚机制——势场边界的触发逻辑对应门控）。

**第二层：意图轨迹规划器（Intent Trajectory Planner）**——学习人类围绕根意图的波动模式（定律一/二）——输入当前意图状态+历史轨迹→输出下一句元**目标状态分布**（允许波动范围/目标跳跃度/目标耦合度——正向维度宽波动带/负向维度窄波动带——定律三）——（对应实证：卡尔曼门控的预测-分配 + dim10/dim48 的目标节奏）。

**第三层：意图引导执行层（Intent Steering Executor）**——目标状态→LLM 采样实时引导——可选实现：磁力引导（logits 偏置）/意图 Mask（token 子集）/虚拟 token 注入——**门控机制：仅在耦合度下降/跳跃度异常/轨迹偏离时启用**（对应实证：vt 通道 117%/103% + Kalman 门控 46%——"何时注入"比"注入什么"重要——语义层解耦定论限定引导的组织层范围）。

#### 与现有范式的本质区别

| 维度 | 传统自回归 | 意图动力学引擎 |
|---|---|---|
| 驱动力 | 局部概率 | **根意图势场 + 局部概率** |
| 状态 | 无持续意图状态 | **可测量的意图状态向量（64 维指纹）** |
| 轨迹 | 平坦或随机漂移 | **人类式波浪与回环**（转折陡度/耦合节奏） |
| 干预 | 无 | **势场边界触发 + 轨迹规划 + 门控执行** |
| 可解释性 | 黑盒 | **维度功能图谱 + 极性分组**（64 维全景） |
| 成本 | 全词表计算 | 可选意图 Mask 输出层降载 |

#### 定位（诚实）

本节为**架构构想**（基于完整实证基础的设计理念）——三层引擎的**完整实现与端到端验证尚未进行**——已实证的组件：根意图锚（vt_ext/oracle 55%/篇核心 d 2.04-2.09）、门控机制（vt_gate_beam 103%/Kalman 修复 r 0.389）、执行通道（vt 注入——优于 logits +16 点）、意图流转监测（句元级跳跃/转折陡度/转移熵——全部显著）、维度功能图谱（dim48=指代链三证合一/dim10=主题组织）——**待实现**：波动模式学习（轨迹规划器）、极性目标分布（正向宽/负向窄波动带）、端到端"自由波动+势场回拉"的生成循环。**这是本文数据支撑的下一步研究方向——"AI 第一次拥有'为什么写'的内在状态"的可操作路径。**

## 6. 结论（基于全部数据重新下结论）

本文实测体系：严格配对 60 对（单段）+ 多段连续 35 组 + 完全未入训独立测试集 32 对（双模型）+ 4956 段滑窗 + 长文档章节对照 + 双语 2×2×3（60 篇长文档）+ 训练干预 **201 runs（22 条件）** + 推理测试 192 回答（常规+抗污染）+ 长文测试 12 篇 + 意图先验/频域数学建模（判据预注册 12 条）——全部数据附 bootstrap 95% CI/BH-FDR/配对检验。按证据强度分列结论：

**1. 判别力结论（强证据——训练域+独立集+双模型三重一致）**
- 白话叙事域：训练域 d 2.7-5.5——未入训独立集 d 1.0-1.9（sent_proj 1.33——p<0.01）——DS/Qwen 双模型方向一致——非训练记忆、非模型特例——双语扩展（v0.67）：段内均值核心跨语言一致（zh d=+2.08/en d=+2.13——嵌入级等价版本）——"AI 段内贴附不足"跨语言存在。

**2. 层级结论（强证据）**
- 句元级最强 → 词级辅助 → 段落级聚合——四层级中段/篇不产生独立判别信息——篇核心（v0.66-5 理论修正）配对级显著（d 2.04-2.09）——锚=被指向的核心思想（非句首）——核心构造稳健（mean>peak>rand——随机锚下人机差距最大——贴附不足非锚效应）。

**3. 边界结论（强证据）**
- 官方评价体/同内容改写/文言复述——独立集三层级双模型归零——边界是文本类型固有——双语扩展（v0.67）：英文篇核心反向（d=-0.73——19 世纪经典多线篇章——语料组织方式调制全局单核心假设——探索性）。

**4. 机制发现（锚定效应/语言机制/锚口径诚实）**
- 生成侧锚定效应（输入原文 AI 贴住——AUC 0.52 vs 0.80）——外部锚（prompt/人类核心）经三层级对照与自指锚不可分辨（Δ<0.005——锚来源非瓶颈——载体限制）——语言机制：主题词密度 d 1.67（人类 8 倍——指纹 53/64 可解释——11 维编码深层组织差异）——锚口径对称性诚实暴露（prompt 锚 d 1.97→对称锚 0.50）。

**5. 意图保持的可计算性（强证据）**
- 指纹投影一致性/篇核心/主题词机制——"意图稳定性=可计算能力子域"配对级成立——跨文本核心锚定（风格锚不传递核心——archives 对天行健核心贴附 0.707<自参照 0.747）——核心是自指的。

**6. 推理期干预实证（v0.68→v0.73-4——201 runs 22 条件——新证据）**
- 判别器推理期价值=监测+评估：监测精准（触发 67% 全真实）——beam 选优 51%（配对 p=0.006——评估>生成）——词级引导位置敏感（逐段 ≤40% 载体限制/开头种子有效）——谱系最高点演进：**句级种子+beam5=82% → vt_seed_beam 三层叠加=117% → vt_gate_beam 门控=103%（成本降 67%——0.37 秒/oracle 点——质量-成本最优推荐）**——虚拟 token 通道优于 logits 载体（+16 点）——无 beam 测试：种子依赖 beam（-1%）/门控 46% 无 beam 最优/beam 净贡献 36 点不可替代——卡尔曼实现问题修复（r 0.147→0.389——先验语义 bug）——策略级预判无独立价值限定旧版实现——训练期接口（φ 可微分通道）已声明。

**7. 推理迁移与能力边界（新证据——解耦定论）**
- 意图锚定对推理准确率零迁移（常规 53%→50%/抗污染 25%→22%——抗污染设计有效排除记忆——**v0.73-5 最强形态复现：新抗污染 12 题 none 39% vs vt 31%——组织层优化第三次验证不转化语义层**）——长文语义保持零差异（0.94+——容量内稳定）——框架同质化代价长文放大（4-gram 重复 d=1.17）——能力边界=组织层（聚焦/长度）——语义层（推理/长程语义）不受影响。

**8. 总体判断（证据分层）**
- 强结论：判别力（三重一致+跨语言）、边界（归零复现）、锚定效应、干预谱系（**201 runs 22 条件——最高点 vt_seed_beam 117%/推荐形态 vt_gate_beam 103%——种子+beam 最小组合 82%**）、解耦（推理/长程语义零迁移）、数据前提验证（频域 F1 FAIL/卡尔曼失配 K1/K2/预测精度 P1 打通）。
- 探索/待复核：英文篇核心反向（语料混杂）、长文档 n=3、推理测试评分噪声（W4 修正记录）、长文 M4 注意力（sdpa 限制）、vt_seed 复述副作用（种子+V 持续注入组合——门控规避）。
- 训练期干预（判别器指纹经映射层 φ 作损失项）为基于完整边界测绘的合理推断——未做端到端验证。

**9. 意图动力学引擎方向（v0.74-5——新的最重要方向）**：基于五条实证定律（潜意识优先/流动特征更本质/维度极性区分/解释性×判别力反比/信息流自由度）提出三层架构构想（根意图势场+意图轨迹规划器+引导执行层）——**从"预测下一个词"到"围绕根意图自由思想"**——全部组件已有实证基础（锚/门控/通道/流转监测/维度图谱）——端到端实现为下一步研究方向（§5.12）。

**贡献**：①可解释判别方法（层级定位）；②严格配对+独立集+双语验证（排除记忆/域混杂/模型特例）；③诚实边界测定（边界模型无关+锚口径对称性）；④推理期干预方法空间完整测绘（**22 条件——最高点 117%——推荐形态 vt_gate_beam 103% 成本降 67%——虚拟 token 通道 + Kalman 门控——最小干预原则（种子+beam=82%）**）；⑤能力解耦实证（意图保持≠推理≠长程语义——组织层与语义层边界地图）；⑥外部主张（卡尔曼注入/频域压缩）数据前提验证（意图轨迹≈白噪声/观测模型失配/预测精度路径打通）；⑦**意图流转测绘**（人类波浪 vs AI 平坦——转折陡度 d=+2.09——金鱼记忆 Hurst 0.62 vs 0.46——转移熵 AI 机械流动——"思维心电图"）；⑧**64 维维度功能图谱**（解释性×判别力反比——未解释 11 维=深层判别信号本体——dim48=指代链三证合一）；⑨**意图动力学引擎架构构想**（五定律+三层架构——从测量到模拟智能的路径）。

**收尾（一句话打动）**：我们把"意图漂移"变成了可测量、可定位、可与人类基线对照、可干预、**可模拟**的几何量——从判别（三重验证）到干预（谱系测绘至 117%——推荐形态 vt_gate_beam 103% 且成本降 67%）到边界（组织层/语义层解耦地图）到**意图动力学（五定律+三层架构——AI 第一次拥有"为什么写"的内在状态）**——一个完整的、可复现的测量-干预-模拟框架——任何研究者可用任意嵌入模型×任意生成模型复现扩展。
